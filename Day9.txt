1. Palindrome Number
------------------------------------------------

Link:
https://leetcode.com/problems/palindrome-number/

Program to determine if a given number is a palindrome.

class Solution(object):
    def isPalindrome(self, x):
        temp = x
        rev_num = 0

        while x > 0:
            rem = x % 10
            rev_num = rev_num * 10 + rem
            x = x // 10

        return rev_num == temp


Example
Input: 121  
Output: True

2. Richest Customer Wealth
------------------------------------------------

Link:
https://leetcode.com/problems/richest-customer-wealth/

Program to calculate the maximum wealth of any customer.

class Solution(object):
    def maximumWealth(self, accounts):
        max_value = 0

        for person in accounts:
            curr_sum = 0
            for val in person:
                curr_sum += val

            if curr_sum > max_value:
                max_value = curr_sum

        return max_value

4. Staircase Pattern
------------------------------------------------

Link:
https://www.hackerrank.com/challenges/staircase/problem

Program to display a right-aligned staircase pattern.

def printStaircase(n):
    for i in range(1, n + 1):
        spaces = " " * (n - i)
        blocks = "#" * i
        print(spaces + blocks)

num = int(input())
printStaircase(num)


Example
Input: 6

Output
     #
    ##
   ###
  ####
 #####
######

6. Mini-Max Sum
------------------------------------------------

Link:
https://www.hackerrank.com/challenges/mini-max-sum/

Program to print the minimum and maximum sum of any 4 elements from 5 numbers.

def mini_max_sum(arr):
    total_sum = sum(arr)
    smallest = min(arr)
    largest = max(arr)

    print(total_sum - largest, total_sum - smallest)


values = list(map(int, input().split()))
mini_max_sum(values)


Example
Input
1 2 3 4 5

Output
10 14

def countTallest(candles):
    highest = max(candles)
    return candles.count(highest)

8. Time Conversion
------------------------------------------------

Link:
https://www.hackerrank.com/challenges/time-conversion/

Program to convert time from 12-hour format to 24-hour format.

def convertTime(time_str):
    if time_str.endswith("AM") and time_str[:2] != "12":
        return time_str[:8]

    elif time_str.endswith("PM") and time_str[:2] != "12":
        hour = str(int(time_str[:2]) + 12)
        return hour + time_str[2:8]

    elif time_str.startswith("12") and time_str.endswith("AM"):
        return "00" + time_str[2:8]

    else:
        return time_str[:8]


time_input = input()
print(convertTime(time_input))


Example
Input
07:05:45PM

Output
19:05:45
